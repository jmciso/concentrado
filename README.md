# Concentrado 🥫

A Pomodoro timer for GNOME (Python + GTK3) with active breaks. UI in English or Portuguese.

*Concentrado* is Portuguese for both "focused" and "tomato paste" (*concentrado de tomate*).

- **Configurable periods**: focus, short break, long break, and focus sessions before a long break.
- **Lives in the top bar**: tomato-paste tin icon (red = focus, green = break, grey = stopped) with the time left next to it.
  Menu: start/pause, skip, restart, show break screen, settings, quit. Middle-click toggles start/pause.
  Closing the window keeps it running in the top bar. No extra packages needed: it speaks the
  StatusNotifierItem protocol directly (GNOME shows it via the AppIndicator extension, on by default in Ubuntu).
- **Full-screen break screen** with a countdown. Dismiss with `Esc` or ✕; the break keeps counting in the top bar.
- **Short breaks** alternate (or you pick) between:
  - a guided **2–3 min physical challenge** (stretching, mobility, mini cardio, breathing, eyes…);
  - a **mini language lesson** (English, Spanish, French, German, Italian) with a **quiz** at the end.
    The lesson only advances when you get at least half right.

## Download

**[Download the latest AppImage](https://github.com/jmciso/concentrado/releases/latest/download/Concentrado-x86_64.AppImage)**
(Ubuntu, Fedora and most distros). Make it executable (`chmod +x Concentrado-x86_64.AppImage`, or
*Properties → Executable as Program*) and open it. On first run it offers to add itself to your app menu.
All versions and checksums are on the [releases page](https://github.com/jmciso/concentrado/releases).

## Install from source


### Requirements

Linux with Python 3 and GTK 3. On Ubuntu/Debian desktops these are usually already there; if not:

```sh
sudo apt install python3-gi gir1.2-gtk-3.0
# optional: notifications and sounds
sudo apt install gir1.2-notify-0.7 gir1.2-gstreamer-1.0 gstreamer1.0-plugins-base
```

For the top-bar icon on GNOME you need the AppIndicator extension. Ubuntu ships it enabled
(`ubuntu-appindicators@ubuntu.com`); on other distros install "AppIndicator and KStatusNotifierItem Support".
KDE and most other desktops support it natively. Without it the app still works: closing the window minimises it.

### Steps

```sh
git clone https://github.com/jmciso/concentrado.git
cd concentrado
./install.sh
```

This needs no sudo. It installs, for the current user only:

- `~/.local/bin/concentrado` (symlink to `concentrado.py`)
- an app-grid entry: `~/.local/share/applications/io.github.jmciso.Concentrado.desktop`
- icons in `~/.local/share/icons/hicolor/`

The installed files point to the cloned folder, so keep it where it is. To update, `git pull`;
re-run `./install.sh` only if the icons changed.

Then open **Concentrado** from the app grid, or run `concentrado`. In Settings you can make it start with your
session and pick the app language (English/Português, which follows the system by default).

If the icon doesn't show in the app grid straight away, log out and back in (GNOME caches icons).

### Uninstall

```sh
concentrado --quit
rm -f ~/.local/bin/concentrado ~/.local/share/applications/io.github.jmciso.Concentrado.desktop \
      ~/.config/autostart/concentrado.desktop
find ~/.local/share/icons/hicolor -name 'io.github.jmciso.Concentrado.*' -delete
rm -rf ~/.config/concentrado ~/.local/share/concentrado   # settings and progress (optional)
```

## Command line

```
concentrado            # open the window (or bring up the running instance)
concentrado --hidden   # start in the top bar only
concentrado --toggle   # start/pause (handy for a GNOME keyboard shortcut)
concentrado --skip | --reset | --show | --quit
concentrado --demo     # minutes count as seconds, for testing
```

## Content

Built-in content lives in `content/<ui-language>/`: `exercises.json` and `lessons/<code>.json`.
Your own files in `~/.config/concentrado/` are added on top:

- `lessons/<anything>.json`: same format as `content/en/lessons/fr.json`. Same `code` adds lessons to that
  language; a new `code` adds a new language.
- `exercises.json`: a list in the format of `content/en/exercises.json`.

To add a UI language: add a block to `i18n.py` and a `content/<code>/` folder.

Icons are generated by `tools_make_icons.py`. Config: `~/.config/concentrado/config.json`.
Stats and progress: `~/.local/share/concentrado/state.json`.

## Development

### Tests

```sh
bash tests/run.sh
```

Runs the unit tests, the AppImage dependency-check tests (with stand-in programs, nothing is installed) and an
end-to-end run of the AppImage contents. The end-to-end part is headless and isolated from your desktop and
settings. It needs `broadwayd` (GTK 3), `dbus-run-session`, `gdbus` and `desktop-file-validate`.

### Building the AppImage

The AppImage is "light": it contains only Concentrado and uses the system's Python 3 and GTK 3. If those are
missing, it explains what's needed and offers to install them (asking for your password first).

```sh
packaging/appimage/build.sh --appdir-only   # just the contents, runnable as dist/Concentrado.AppDir/AppRun
packaging/appimage/build.sh                 # also packs dist/Concentrado-<version>-x86_64.AppImage
```

Packing needs [appimagetool](https://github.com/AppImage/appimagetool/releases). Put it at
`~/.cache/concentrado-build/tools/appimagetool-x86_64.AppImage` or point `APPIMAGETOOL` at it. To pin the tool,
put its sha256 in `packaging/appimage/appimagetool.sha256`.

On first run, the AppImage offers to add itself to the app menu (Settings → *Show in the app menu* turns it
on or off). If you move or update the AppImage file, open it once from its new place and the menu entry
follows it.
